# bin/ placeholder

```bash
node scripts/fetch-openvpn-binaries.mjs --platform linux-x64 --source <dir|archive|url>
```

The pinned version and the expected files are declared in
[`openvpn-binaries.json`](../../../openvpn-binaries.json).
